Glossary

The vocabulary of the sport. Every term used across the lessons, defined once, here.

Complexity

Big O  O(f(n))
An upper bound on how a cost grows as the input grows. Constants and lower-order terms are discarded, because at contest scale only the growth shape decides pass or fail. n²/2 + 3n + 7 is O(n²).
Time complexity
How the number of operations grows with n. The thing you compare against your budget.
Space complexity
How memory grows with n. Judged against a memory limit, usually 256 MB. An n × n table with n = 105 is 1010 cells — impossible, regardless of time.
Auxiliary space
Memory your algorithm allocates beyond the input itself. Sorting in place is O(1) auxiliary; building a set of every element is O(n).
Constant factor
The multiplier Big O throws away. Irrelevant to the complexity class, but decisive when you are borderline — and it is why Python and C++ solutions of identical complexity do not both pass.
Amortised
A cost averaged over a sequence of operations. list.append is occasionally O(n) when the array must grow, but n appends total O(n), so it is called amortised O(1). Budget against the total, not the worst single call. See Python Operation Costs.
Complexity classes, cheapest first
O(1) constant · O(log n) logarithmic · O(n) linear · O(n log n) linearithmic · O(n²) quadratic · O(n³) cubic · O(2ⁿ) exponential · O(n!) factorial.

Contest mechanics

Constraints
The bounds printed in the problem statement (1 ≤ n ≤ 2·105). The most informative line in the problem — it tells you the intended complexity before you write anything. See Lesson 0001.
Budget
Roughly 108 simple operations per second on a judge. Your total allowance for the whole solution. See The Complexity Budget Table.
TLE  Time Limit Exceeded
Your solution was correct but too slow. Almost always a wrong complexity class, not a slow line.
MLE  Memory Limit Exceeded
You allocated more than the limit. Usually a table sized on the wrong variable.
WA  · RE  · AC
Wrong Answer — correct-shaped output, wrong content. Runtime Error — a crash, in Python usually an index error or recursion limit. Accepted — you're done.
Setter  ·  Editorial
The setter is the author of the problem; they chose the constraints deliberately. The editorial is the official solution published afterwards — reading them is the fastest way to improve.
Sum-of-n clause
“the sum of n over all test cases does not exceed 2·105”. Budget against that sum, not per test case. Easy to misread and TLE on.
PyPy
An alternative Python implementation with a JIT compiler, offered by some judges. Often several times faster on loop-heavy code. If it is on the language list, use it.

Techniques

Brute force  complete search
Try every possibility. Always correct, usually too slow — but when the constraints are small it is the intended solution, and reaching for something clever wastes contest time. The two names are interchangeable; USACO Guide and CPH both prefer complete search. See Lesson 0005.
Search space
The set of all candidate answers a complete search walks through: every subset (2n), every permutation (n!), every assignment (kn). Sizing it before coding is the whole skill — it is the number you compare against the budget.
Backtracking
Building a solution one choice at a time, and undoing the last choice when the partial solution reaches a dead end. The recursive shape of complete search, used when you want to abandon whole branches rather than generate every candidate in full.
Pruning
Cutting off a branch of a backtracking search as soon as it cannot lead to a valid solution. Does not change the complexity class — the worst case stays exponential — but can improve the constant by orders of magnitude. One of the few places where “still O(2n)” and “now passes” are both true.
Meet in the middle
Split the input in half, enumerate each half separately (2n/2 each), then combine. Since 2n/2 = √(2n), it takes the square root of the work. The fingerprint is n ≤ 40 on a subset-flavoured question.
Binary search
Halve the search space each step, giving O(log n). Requires the data to be sorted, or the property being searched to be monotonic. See Lesson 0003.
Binary search on the answer
Instead of searching the array, search the answer space: guess a value, ask a yes/no question about it, halve. Turns “find the smallest workable X” into O(log(range) × cost of the check).
Monotonic  predicate
A yes/no property that, once it flips, never flips back — no no no yes yes yes. Monotonicity is what licenses a binary search. Without it, halving may discard the answer.
Two pointers
Two indices sweeping an array, each moving forward only. Collapses O(n²) to O(n) because each pointer traverses the array at most once in total, however the loops are nested. See Lesson 0004.
Sliding window
The two-pointer shape where the pair bounds a contiguous range that grows at the right and shrinks at the left. Standard for “longest/shortest subarray such that …”.
Prefix sums
Precompute running totals once in O(n), then answer any range-sum query in O(1) as pre[j] - pre[i]. Trades O(n) memory for removing a loop.
Invariant
A statement that stays true on every iteration of a loop. The tool for convincing yourself a two-pointer or binary-search loop is correct — and for finding the bug when it isn't.
Greedy
Take the locally best option at each step and never reconsider. Fast — usually O(n) or O(n log n) — but only correct when the problem has the structure to support it, which must be argued, not assumed.

Bitwise

Bitmask
An integer used to represent a subset: bit i is 1 exactly when item i is in the set. The integers 0 to 2n−1 are then precisely the subsets, so for mask in range(1 << n) enumerates all of them. See Lesson 0006 and the cheat sheet.
Popcount  population count
The number of 1 bits in an integer, i.e. the size of the set it represents. mask.bit_count() in Python 3.10+, else bin(mask).count("1"). Using it removes the inner loop, taking subset enumeration from O(2n·n) to O(2n).
XOR  ^
1 where two bits differ. Its own inverse: x ^ x = 0 and x ^ 0 = x, and it is associative and commutative. XOR-ing a whole list cancels every value appearing twice, leaving the one that appears once.
Shift  << >>
x << k multiplies by 2k; x >> k floor-divides by it. 1 << n is the standard way to write 2n in contest code.
Complement  the Python trap
Set complement is not ~a in Python. Python integers have unlimited precision, so there is no width to invert within and ~a is −a−1. Use full ^ a where full = (1 << n) - 1. This is the one piece of C++ bitmask advice that does not port.
